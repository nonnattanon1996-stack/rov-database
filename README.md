# คลังข้อมูล RoV

เว็บไซต์แบบ static (ไม่ต้องมีเซิร์ฟเวอร์หลังบ้าน) แพตช์ข้อมูล: **Beta 55 – Abyssal Rift + Hotfix 15 ต.ค. 2026** (ตรวจ 2026-10-23)

## เปิดดู
- ดับเบิลคลิก `index.html` ได้เลย (ใช้ได้ทั้งแบบเปิดไฟล์ตรง ๆ และผ่านเซิร์ฟเวอร์)
- หรือรันเซิร์ฟเวอร์ในเครื่อง: `python3 -m http.server 8000` แล้วเปิด http://localhost:8000

## เอาขึ้นออนไลน์
- **GitHub Pages**: อัปโหลดทั้งโฟลเดอร์ขึ้น repo แล้วเปิด Settings → Pages → Deploy from branch
- **Netlify / Cloudflare Pages / Vercel**: ลากโฟลเดอร์นี้ไปวาง (Build command: ไม่ต้องใส่, Publish directory: `.`)
- โดเมนของตัวเอง: อัปโหลดทั้งโฟลเดอร์ไปที่ public_html ของโฮสต์

## โครงสร้าง
```
index.html                หน้าเดียว (ฮีโร่ · ดราฟต์ · ไอเทม · จำลองดาเมจ · ที่มา)
assets/app.css            สไตล์หลัก + หน้าเปิด
assets/app.js             คลังฮีโร่ + จำลองดราฟต์
assets/db.js              สถานะ/สกิล ไอเทม จำลองดาเมจ (คอมโพเนนต์ <rov-db>)
assets/intro.js           หน้าเปิดแบบการ์ดวนเป็นวงกลม → ส่วนโค้ง
assets/img/               รูปฮีโร่ สกิล และไอเทม
data/rov-data.js          ข้อมูลสายการเล่น ทางแพ้ชนะ สถิติแข่ง
data/db-data.js           สถานะเลเวล สกิล ไอเทม พลังแฝง
```

## อัปเดตเมื่อมีแพตช์ใหม่
ข้อมูลฮีโร่/ไอเทมสร้างจากสคริปต์ `db/build.py` และ `merge/build_merge2.py` ในโปรเจกต์ต้นทาง แก้ `db/meta.json` แล้วรันตามลำดับ
`python3 db/build.py && python3 merge/build_merge2.py && python3 merge/build_site.py` จะได้โฟลเดอร์ `site/` ใหม่
